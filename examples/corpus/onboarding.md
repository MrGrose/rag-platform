# Customer Onboarding

Every new customer starts with a 14 day trial that includes all Pro features.

Onboarding has three steps: workspace setup, data import and team invitation.

The implementation team runs a 60 minute kickoff call within the first 5 business days.

Data import supports CSV, JSON and direct API upload. Historical data older than 3 years is imported on request only.

The trial converts to a paid plan automatically unless cancelled before the last trial day.
