# Security Overview

Data at rest is encrypted with AES-256 and data in transit uses TLS 1.3.

Access to production requires multi-factor authentication and is reviewed every quarter.

Audit logs are retained for 12 months and are available to Enterprise customers on request.

We run annual penetration tests and a continuous vulnerability scanner.

The platform is hosted in ISO 27001 certified data centres and is SOC 2 Type II audited.
